# Omarchy Plugins

- [Omacal](https://github.com/brianblakely/omacal) - Drop-in clock replacement
  with mini calendar
- [Omasnap](https://github.com/brianblakely/omasnap) - Screenshot and screen
  recording overlay
- [Omastonk](https://github.com/brianblakely/omastonk) - Stock tickers in the
  Omarchy bar, with charts
- [Omanote](https://github.com/brianblakely/omanote) - Secure scratch note in
  the Omarchy bar
- [Omanews](https://github.com/brianblakely/omanews) - Headlines in the Omarchy
  bar, with instant access to commentary
- [OmaLED](https://github.com/brianblakely/omaled) - Dim the Omarchy bar when
  not in use
- [OmaHUD](https://github.com/brianblakely/omahud) - Workspace indicator for
  users who hide the Omarchy bar
- [Peek](https://github.com/brianblakely/peek) - Peek behind floating windows
- [Blink](https://github.com/brianblakely/blink) - Briefly flash an indicating
  border over the active window, for those who use Omarchy in gapless mode
